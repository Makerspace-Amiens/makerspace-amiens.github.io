# Makerspace UniLaSalle Amiens

Site vitrine du Makerspace d'UniLaSalle Amiens : <https://makerspace-amiens.fr>

Le site est une page unique et autonome (`index.html`) : toutes les ressources (scripts, modèle 3D, polices) y sont intégrées. Elle est déployée sur GitHub Pages par le workflow `.github/workflows/pages.yml` à chaque push sur `main`.
